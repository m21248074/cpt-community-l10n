# 繁體中文術語表與翻譯慣例

翻譯檔：`zh-TW/Chinese Traditional.ts`。新增或修改譯文時請遵循下列用詞，保持一致。

## 原則

- **IOS 指令類名稱維持英文**：`OSPF`、`EIGRP`、`ACL`、`VTP`、`Zone Pairs`、`Enable Secret` 等，因為使用者需要與 IOS 輸出對照。
- 協定訊息名稱與狀態（`Hello`、`Update`、`Sync`、`Configuration Ack`、`Blocked`、`ESTABLISHED`）維持英文，只翻句子其餘部分。
- 字型名稱、數字、快捷鍵（`Ctrl+S`）、`Activity Wizard`、`Packet Tracer`、`WPF`、`CC` 維持英文。
- 必須原樣保留的佔位符：`%1`、`%2`…、`[[MODULE_NAME]]`、`[[DEVICE_TYPE]]` 等、HTML 標籤與 `&amp;`、`&lt;` 等實體。
- 選單快捷鍵：`&File` 譯為「檔案(&F)」，並保留原本的字母。
